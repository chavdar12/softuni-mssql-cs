# SoftUni MS SQL

Solutions for the SoftUni Databases Basics – MS SQL Server course. One `Problem-NN.sql` file per problem; the
*(setup)* scripts create the sample databases (Diablo, Geography, Gringotts, SoftUni, Bank) that the queries use.

## Run

Run a setup script once, then any problem, in SSMS / Azure Data Studio or with `sqlcmd`:

```bash
sqlcmd -S localhost -U sa -i 005-Subqueries-and-JOINs/Resources/Geography-Database.sql
sqlcmd -S localhost -U sa -d Geography -i 005-Subqueries-and-JOINs/Problem-12.sql
```
